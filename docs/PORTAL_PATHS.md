# مسارات البوابات (نفس الدومين)

التطبيق يحدد البوابة من **مسار الرابط** — لا حاجة لنطاقات فرعية.

| المسار | البوابة |
|--------|---------|
| `/` | اختيار نوع المستخدم (عميل / طالب IoT / موظف) |
| `/customer` | تسجيل دخول العميل |
| `/student` | تسجيل دخول طالب IoT |
| `/enterprise` | تسجيل دخول الموظف |

مثال: `https://dashboard.iot365.tech/student`

الاستضافة الثابتة (Render) تحتاج إعادة توجيه SPA: `/*` → `/index.html` (موجود في `render.yaml`).
