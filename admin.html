قواعد الأمان Firestore Rules

تأكد من نشر قواعد الأمان لدعم صلاحيات المسؤول بالكامل.

function isAdmin() {
  return request.auth != null && (
    get(/databases/$(database)/documents/users/$(request.auth.uid)).data.role == 'admin'
  );
}
